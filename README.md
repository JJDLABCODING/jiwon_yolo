# jiwon_yolo

콜라와 킥보드 이미지로 YOLO 객체 탐지 모델을 훈련하는 프로젝트입니다.

## 클래스

| 번호 | 이름 |
|---|---|
| 0 | 콜라 |
| 1 | 킥보드 |

클래스 번호는 `이미지/classes.txt`의 줄 순서와 같습니다. 첫 줄이 0번입니다.

## 이미지 폴더 구조

클래스마다 폴더가 하나씩 있고, 각 폴더에 이미지와 라벨 파일이 함께 들어 있습니다.

```
이미지/
├── classes.txt
├── 콜라/
│   ├── 콜라_0001.jpg
│   ├── 콜라_0001.txt
│   └── ...
└── 킥보드/
    ├── 킥보드_0001.jpg
    ├── 킥보드_0001.txt
    └── ...
```

- 라벨 파일(`.txt`)은 이미지 파일과 **이름이 같고 확장자만 다릅니다**. 예: `콜라_0001.jpg` ↔ `콜라_0001.txt`
- 이미지 폴더는 앞으로 더 추가됩니다. 새 폴더도 같은 구조를 따릅니다.

## 라벨 형식

YOLO 형식입니다. 박스 하나가 한 줄이고, 값은 공백으로 구분합니다.

```
<클래스 번호> <중심 x> <중심 y> <너비> <높이>
```

좌표와 크기는 이미지의 너비·높이로 나눈 0~1 사이 값입니다.

```
0 0.493798 0.507752 0.258915 0.742636
```

## 주의

- `*_box.jpg` 파일은 박스를 그려 넣은 확인용 이미지입니다. **학습 데이터에 넣지 마세요.**
- `sources.csv`는 이미지를 받아 온 주소를 기록한 파일이라 학습과는 관계없습니다.
